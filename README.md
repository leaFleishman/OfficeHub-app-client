# OfficeHub

ממשק Web לניהול סביבת עבודה משרדית משותפת. המערכת מאפשרת לעובדים להזמין חדרי ישיבות ולנהל פניות, ולמנהלים ולאדמינים לנהל את משאבי החברה והבניין בהתאם להרשאות שלהם.

## יכולות עיקריות

- התחברות לחשבון ושמירת מצב המשתמש בין טעינות.
- לוחות בקרה נפרדים לעובד, למנהל חברה ולאדמין.
- צפייה בחדרים ובזמינותם, יצירת הזמנות וניהול הזמנות קיימות.
- פתיחת פניות, צפייה בפניות ועדכון תגובה או סטטוס.
- ניהול עובדים, חברות וחדרים במסכים המתאימים לתפקיד.
- עריכת פרטי פרופיל ושינוי סיסמה.

## טכנולוגיות

- React 19 ו-TypeScript 6.
- Vite 8 לבנייה ולהרצת סביבת הפיתוח.
- React Router לניהול ניווט ונתיבים.
- TanStack Query לניהול נתונים שמתקבלים מהשרת ועדכונם לאחר פעולות.
- Axios לתקשורת HTTP.
- React Hook Form ו-Zod לבניית טפסים ולאימות נתונים.
- Tailwind CSS 4 לצד קובצי CSS של האפליקציה.
- Nginx להגשת הגרסה שנבנתה ב-Docker.

## דרישות מקדימות

- Node.js בגרסה התואמת ל-Vite 8 (תמונת ה-Docker של הפרויקט משתמשת ב-Node.js 22).
- npm.
- שרת API זמין. קוד השרת אינו כלול במאגר זה.

## הפעלה מקומית

1. התקינו את התלויות:

   ```bash
   npm ci
   ```

2. הגדירו כתובת בסיס לשרת ה-API בקובץ `.env.local` בשורש הפרויקט:

   ```dotenv
   VITE_API_BASE_URL=http://localhost:5000
   ```

   החליפו את הכתובת בכתובת הבסיס של סביבת השרת שלכם. משתני `VITE_*` נכללים בקוד הדפדפן, ולכן אין לשמור בהם סודות או מפתחות פרטיים.

3. הפעילו את שרת הפיתוח:

   ```bash
   npm run dev
   ```

   Vite יציג בטרמינל את כתובת הפיתוח המקומית.

## בנייה והרצה באמצעות Docker

כתובת ה-API מועברת בזמן בניית תמונת Docker, מפני שהמשתנה מוטמע בקובצי הלקוח בזמן הבנייה:

```bash
docker build --build-arg VITE_API_BASE_URL=https://api.example.com -t officehub-client .
docker run --rm -p 8080:80 officehub-client
```

לאחר ההפעלה, הממשק יהיה זמין בכתובת `http://localhost:8080`. יש להחליף את `https://api.example.com` בכתובת ה-API המתאימה. Nginx מוגדר להחזיר את `index.html` עבור נתיבי האפליקציה, כדי לאפשר טעינה ישירה של נתיבי React Router.

## מבנה הפרויקט

```text
src/
├── api/          פונקציות התקשורת לשרת, לפי תחום
├── auth/         הקשר התחברות, מצב משתמש ונתיבים מוגנים
├── components/  רכיבים משותפים וטפסים
├── features/    תכונות לפי תחום: הזמנות, לוחות בקרה, עובדים, פניות וחדרים
├── hooks/       Hooks לשאילתות ולפעולות API
├── pages/       מסכי האפליקציה
├── routes/      הגדרות הנתיבים ומעטפת היישום
└── types/       טיפוסי הנתונים המרכזיים
```

### זרימת הנתונים

`src/main.tsx` מאתחל את React, את `QueryClientProvider` ואת הראוטר. `src/routes/RootLayout.tsx` עוטף את היישום ב-`AuthProvider`; מסכי האפליקציה עצמם נטענים דרך הנתיבים ב-`src/routes/AppRoutes.tsx`. קריאות השרת מרוכזות ב-`src/api/`, כשהן משתמשות בלקוח Axios המשותף שב-`src/api/client.ts`. שאילתות ושינויי נתונים במסכים נעשים באמצעות TanStack Query, דרך ה-hooks שב-`src/hooks/`.

## התחברות והרשאות

- ההתחברות מתבצעת מול `POST /auth/login`; פרטי המשתמש נשמרים במצב האפליקציה והטוקן נשמר ב-`localStorage`.
- בטעינת האפליקציה, אם קיים טוקן, נשלחת בקשת `GET /auth/me` לשחזור פרטי המשתמש. התנתקות מסירה את הטוקן ומחזירה למסך ההתחברות.
- הנתיבים המוגנים בודקים את תפקיד המשתמש בצד הלקוח. במצב הנוכחי, מסכי ניהול חדרים, חברות וכל הפניות מוגבלים לאדמין; מסכי ניהול עובדים, ניהול וחברות מוגבלים לאדמין או למנהל; מסך החברה שלי מוגבל למנהל.
- ההרשאות בצד הלקוח נועדו להתאים את חוויית המשתמש, אך השרת חייב לאמת הרשאות בכל פעולה ובכל נקודת API.

## ממשק שרת

הלקוח מצפה ש-`VITE_API_BASE_URL` יצביע לשרת התואם לנתיבים הבאים. הקידומות הן יחסיות לכתובת הבסיס:

| תחום | נתיבים בשימוש |
| --- | --- |
| התחברות | `/auth/login`, `/auth/me` |
| הזמנות וחדרים | `/bookings`, `/bookings/mine`, `/rooms`, `/rooms/available`, `/rooms/:id/bookings` |
| חברות | `/companies`, `/companies/mine` |
| עובדים | `/employees`, `/employees/:id` |
| פניות | `/inquiries`, `/inquiries/mine`, `/inquiries/:id` |
| פרופיל | `/profile`, `/profile/password` |
| לוחות בקרה | `/dashboard/employee`, `/dashboard/company`, `/dashboard/building` |

קריאות API כוללות פעולות קריאה ופעולות שינוי (יצירה, עדכון, מחיקה ושינוי סטטוס); יש לעיין במודולים שבתיקיית `src/api/` כדי לראות את שיטת HTTP והפרמטרים המדויקים לכל פעולה. מבני הבקשה והתשובה המרכזיים מוגדרים ב-`src/types/domain.ts`.

## שפה ועיצוב

הממשק מוגדר בעברית ובכיווניות מימין לשמאל. הגדרות המסמך נמצאות ב-`index.html`, סגנונות האפליקציה ב-`src/index.css` וב-`src/App.css`, וקובץ העיצוב נטען גם באמצעות תוסף Tailwind של Vite.
